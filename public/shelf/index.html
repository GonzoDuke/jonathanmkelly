Only copy

Two Netlify sites hold code that exists nowhere else. vinyloracle and oracleofmusic have deployed serverless functions (api, discogs, and for the latter itunes) that cannot be downloaded over HTTP. Their front ends are saved in the-music-oracle/legacy/; the functions are not. Keep both sites up until the Music Oracle revival has taken what it needs.

Needs setup

None of the eleven local clones have dependencies installed. You can read, edit, commit and push without installing anything. You need npm install only to run a project or verify a change works.
